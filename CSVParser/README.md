\# CSV Parser



A Java program that counts word frequencies in a text file and exports the results to CSV.



\## Description



This program reads a text file (`input.txt`), extracts words using regex pattern matching, counts the frequency of each word, sorts them by frequency (descending) and alphabetically, and writes the results to a CSV file (`output.csv`).



\## Features



\-  Reads text files with multilingual support (English, Russian)

\-  Case-insensitive word matching

\-  Sorts words by frequency (highest first)

\-  Alphabetical sorting for words with same frequency

\-  Exports to CSV format
